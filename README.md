# JavaScript Learning Journey

Personal practice repository documenting my self-taught JavaScript learning progress.

This repo contains many small, focused scripts I wrote while learning core JavaScript concepts through daily practice. Each file explores a specific topic or problem so I can build strong fundamentals step by step.

## Topics Covered

- Variables, data types, and basic operations
- Conditionals and loops
- Functions (regular, arrow, anonymous, recursive)
- Closures and scope
- Arrays and common methods (`map`, `filter`, `reduce`, `find`, etc.)
- Objects and constructors
- String manipulation and regular expressions
- DOM basics and simple interactivity
- Math problems (primes, factorials, Fibonacci, LCM/HCF, Armstrong numbers, etc.)
- Small utilities and experiments

## Purpose

This is a learning journal, not a polished library. The goal is consistent daily practice and deep understanding of the language fundamentals.

I am a self-taught developer building practical skills for automation and web development.

**Note:** File names are intentionally descriptive so I can quickly find past practice exercises.
